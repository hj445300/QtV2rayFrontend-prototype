# 非平稳雷达环境下的时序基础模型与事件触发贝叶斯低秩适应跟踪

## 摘要

本方案面向非平稳雷达环境中的多目标跟踪问题，研究“雷达时序基础模型 + 可微贝叶斯滤波 + 位置-速度联合创新 + 事件触发贝叶斯 LoRA 在线适应”统一框架。核心目标是在目标运动模式、雷达噪声、杂波和传感器状态不断变化时，以较低计算开销实现可靠、可校准、可解释的在线多目标跟踪。

研究重点不是简单叠加大模型、滤波器和 LoRA，而是解决以下核心问题：如何学习复杂雷达时序表示；如何将神经模型与概率状态推理统一；如何通过联合创新识别模型失配；以及如何利用事件触发的低秩后验更新实现稳定在线适应。

---

## 一、博士论文题目与总体目标

### 1.1 推荐题目

中文：

> **非平稳雷达环境下基于时序基础模型与事件触发贝叶斯低秩适应的多目标跟踪方法研究**

英文：

> **Multi-Target Radar Tracking in Non-Stationary Environments via Temporal Foundation Models and Event-Triggered Bayesian Low-Rank Adaptation**

偏估计理论和信号处理的备选题目：

> **面向非平稳雷达跟踪的可微贝叶斯状态推理与事件触发在线适应方法研究**

### 1.2 总体目标

构建一个面向非平稳雷达场景的目标跟踪框架，使其具备：

1. 复杂雷达时序和目标运动的表示学习能力；
2. 带后验不确定性的状态估计能力；
3. 对运动模式变化、量测异常和模型失配的检测能力；
4. 仅更新少量参数的低成本在线适应能力；
5. 在机动、杂波、漏检和噪声漂移条件下的稳定跟踪能力；
6. 面向边缘设备的实时部署能力。

最终输出不只是点估计，而是完整后验：

```text
p(x_t | z_1:t)
```

并输出状态估计、协方差、目标存在概率、运动模式概率和关联置信度。

## 二、研究背景与问题定义

传统雷达跟踪通常依赖固定运动模型、固定噪声统计和周期性参数更新。在真实场景中，目标可能经历匀速、加速、转弯和突发机动，雷达还可能出现杂波、漏检、虚警、重尾噪声、系统性偏置和采样间隔变化。固定模型和一次性训练的深度模型容易产生模型失配、过度自信和长期漂移。

本研究将问题定义为：给定不规则、带噪且可能存在关联错误的雷达量测序列 `z_1:t`，在线估计多目标状态及其后验分布：

```text
p(x_t^k, m_t^k | z_1:t)
```

其中 `x_t^k` 为第 `k` 个目标的运动状态，`m_t^k` 为运动模式。系统需要同时判断：

- 当前目标处于什么运动模式；
- 当前量测是否可信；
- 是否需要触发模型适应；
- 应更新动态模型、量测模型还是噪声模型；
- 更新后是否仍保持概率校准和跟踪稳定。

## 三、六个研究分支的文献地图

### 分支一：经典贝叶斯滤波与多目标跟踪

**代表思路：**

- KF、EKF、UKF、粒子滤波；
- IMM 用于匀速、匀加速、协调转弯等模式切换；
- PDA、JPDA、MHT 和 RFS/PHD/GM-PHD 用于数据关联和目标数不确定；
- NIS/NEES 用于创新一致性检验；
- 轨迹管理用于目标生成、确认、保持和删除。

**优势：**物理解释清晰、实时性好、概率状态估计成熟。

**不足：**运动模型和噪声统计依赖先验，面对复杂非线性、非高斯杂波和跨域变化时适应能力有限。

**本课题衔接：**以可微 EKF/UKF/IMM 或粒子滤波作为可靠推理核心，由基础模型动态预测运动转移、`Q`、`R` 和模式概率。

### 分支二：深度神经滤波与可微状态空间模型

**代表思路：**

- Deep Kalman Filter、Neural Kalman Filter；
- 神经网络学习状态转移、量测模型或噪声协方差；
- 可微 EKF/UKF 将滤波步骤纳入端到端训练；
- Neural ODE/SDE、深度状态空间模型和神经粒子滤波；
- 物理模型与残差网络结合。

**优势：**能够建模复杂非线性和数据驱动残差。

**不足：**不确定性可能不校准，神经模型容易过度自信，在线更新容易不稳定。

**本课题衔接：**神经时序模型负责复杂表征和参数预测，贝叶斯滤波负责后验传播、物理约束和协方差更新。

### 分支三：雷达时序模型、点云模型与时序基础模型

**代表思路：**

- 点迹集合编码、PointNet/Set Transformer；
- Range-Doppler、Range-Angle 图的 CNN/ViT 编码；
- Temporal Transformer、时空图网络、Mamba/SSM；
- Track Query、轨迹预测和多目标交互建模；
- 掩码重建、下一帧预测、轨迹对比学习等自监督预训练。

**优势：**学习复杂运动、目标散射特征和跨时间上下文。

**不足：**许多工作面向单一数据集，缺乏跨场景基础模型和概率状态推理；雷达预训练资源和统一基准仍不充分。

**本课题衔接：**构建面向点迹和雷达时序的基础编码器，采用集合编码处理每帧变长点迹，采用时间感知模型处理不规则采样，并通过 Track Query 输出目标级表征。

### 分支四：不确定性量化与贝叶斯深度学习

**代表思路：**

- 变分推断、Laplace 近似、深度集成和 MC Dropout；
- 概率回归、异方差噪声、深度状态空间后验；
- NLL、CRPS、NIS、NEES、覆盖率和 ECE 校准；
- 鲁棒 Student-t 似然处理异常量测和重尾噪声；
- 模型不确定性与观测噪声不确定性分解。

**优势：**可以衡量预测可信度并支持风险控制。

**不足：**大模型后验成本高；参数不确定性与状态后验往往没有统一传播；在线环境变化下容易过度自信。

**本课题衔接：**同时维护状态不确定性和低秩适配参数后验，并通过 KL 约束、鲁棒似然和校准损失控制在线更新。

### 分支五：事件触发估计与自适应跟踪

**代表思路：**

- 基于创新或信息增益的非周期采样；
- NIS/NEES 阈值、CUSUM、Page-Hinkley 变化检测；
- 资源受限传感器网络和低能耗滤波；
- 事件触发控制与分布式状态估计；
- 根据残差模式切换模型或调整 `Q/R`。

**优势：**降低通信、更新和计算成本。

**不足：**很多方法仅使用单一残差和固定阈值，难以区分机动、传感器异常和错误关联；与深度模型后验适应的结合不足。

**本课题衔接：**使用位置-速度联合创新、创新协方差、滑动窗口和变化检测构造事件触发器，并将残差模式映射到不同适配器。

### 分支六：参数高效微调、LoRA 与在线持续学习

**代表思路：**

- LoRA、QLoRA、Adapter、Prefix/Prompt Tuning；
- 只更新低秩矩阵以降低显存和计算；
- 贝叶斯 LoRA、变分后验和 Laplace 低秩近似；
- 测试时适应、域适应、持续学习和 replay；
- KL 正则、参数锚定和鲁棒损失抑制灾难性遗忘。

**优势：**适合少样本、跨域和资源受限在线适应。

**不足：**在雷达状态估计中，适配参数后验如何影响状态后验尚未充分研究；`A/B` 因子不唯一、异常量测污染和稳定性保证是重要问题。

**本课题衔接：**冻结基础模型主体，只在注意力、运动/量测参数头和 Track Query 层插入贝叶斯 LoRA，并由事件触发器决定是否更新。

## 四、研究空白与核心假设

### 4.1 研究空白

现有工作通常只覆���上述某一个或两个分支，缺少以下统一框架：

1. 雷达时序基础模型与贝叶斯状态推理的统一接口；
2. 位置和速度联合创新对运动失配、量测异常的区分机制；
3. 事件触发与低秩参数后验更新的耦合；
4. 参数后验不确定性向状态后验传播的方法；
5. 在线适应的稳定性、校准性和计算开销的联合评价。

### 4.2 核心假设

1. 雷达时序预训练可以学习跨场景的运动和量测质量表征；
2. 基础模型预测动态参数，贝叶斯滤波执行状态推理，比纯神经回归更容易保持可靠不确定性；
3. 位置-速度联合创新比单一位置残差更早、更准确地识别运动模式变化；
4. 事件触发的贝叶斯 LoRA 可以在降低更新开销的同时实现快速适应；
5. 鲁棒似然和 KL 约束可以降低异常量测污染，维持长期跟踪稳定性。

## 五、总体技术框架

```text
雷达点迹 / Range-Doppler 图 / 量测序列
                    |
                    v
          Radar Encoder（集合/图/视觉编码）
                    |
                    v
     Temporal Foundation Model（Transformer/Mamba）
                    |
       +------------+-------------+
       |            |             |
       v            v             v
   动态模型头    量测质量头    Track Query
   F,Q,模式      R、关联度      多目标表征
       |            |             |
       +------------+-------------+
                    v
          可微 Bayesian Filter
          EKF / UKF / IMM / PF
                    |
                    v
    状态后验、协方差、存在概率、运动模式概率
                    |
                    v
      位置-速度联合创新与变化检测
                    |
          +---------+---------+
          |                   |
       不触发              触发更新
          |                   |
          |                   v
          |      鲁棒贝叶斯 LoRA 后验更新
          |                   |
          +---------<---------+
```

### 5.1 输入与状态

第一阶段建议使用点迹级输入：

```text
z_t^i = [range, azimuth, elevation, radial_velocity, SNR, RCS, delta_t]
```

二维状态可定义为：

```text
x_t = [p_x, p_y, v_x, v_y, a_x, a_y]^T
```

三维场景可扩展为位置、速度和加速度的九维状态。每帧点迹数量可变，使用 Set Encoder 或图神经网络得到帧级表示。

### 5.2 时序基础模型

```text
h_t = SetEncoder(Z_t)
H_1:T = TemporalModel(h_1, ..., h_T, delta_t_1:T)
```

模型应显式输入采样间隔 `delta_t`，避免把不规则雷达采样误认为固定频率。建议先实现 Set Transformer + Temporal Transformer，再比较 Mamba/SSM 的长序列效率。

预训练任务包括：

- 掩码点迹重建；
- 下一帧点迹/状态预测；
- 时间顺序判别；
- 同一目标轨迹片段对比学习；
- 运动模式分类；
- 概率状态预测。

### 5.3 Track Query 多目标表示

为每个目标维护查询向量：

```text
q_t^k = TrackDecoder(q_{t-1}^k, H_t)
```

输出：

```text
x_hat_t^k, P_hat_t^k, p_exist_t^k, p_mode_t^k, p_assoc_t^k
```

数据关联可先采用 Hungarian 作为可复现基线，再研究可微关联、JPDA 近似或 Track Query 匹配损失。

### 5.4 可微贝叶斯状态空间模型

动态模型：

```text
x_t = F_t x_{t-1} + g_theta(H_t, q_t) + w_t
w_t ~ N(0, Q_t)
```

量测模型：

```text
z_t = h_theta(x_t, H_t) + v_t
v_t ~ N(0, R_t)
```

基础模型动态输出 `F_t`、`Q_t`、`R_t` 和运动模式概率。滤波核心执行：

```text
x_pred = F_t x_prev
P_pred = F_t P_prev F_t^T + Q_t
K = P_pred H^T (H P_pred H^T + R_t)^(-1)
x_post = x_pred + K (z_t - H x_pred)
P_post = (I - K H) P_pred
```

对强非线性场景采��� EKF/UKF，对多模式机动采用神经 IMM，对严重非高斯场景再研究粒子滤波。

### 5.5 位置-速度联合创新

定义：

```text
r_p,t = p_obs,t - p_pred,t
r_v,t = v_obs,t - v_pred,t
r_t = [r_p,t; r_v,t]
S_t = H_t P_pred,t H_t^T + R_t
NIS_t = r_t^T S_t^(-1) r_t
```

为抑制偶发噪声，采用滑动窗口和 CUSUM：

```text
g_t = max(0, g_{t-1} + NIS_t - nu)
```

当 `g_t > h` 且关联置信度高于阈值时，才触发在线适应。残差模式用于选择更新对象：

| 残差模式 | 可能原因 | 更新策略 |
|---|---|---|
| 位置高、速度低 | 位置量测偏差 | 更新量测适配器 |
| 位置低、速度高 | 多普勒/速度模型异常 | 更新速度相关适配器 |
| 位置和速度均高 | 机动或动态模型失配 | 更新运动适配器 |
| 突发极大 | 虚警或错误关联 | 拒绝更新、采用鲁棒权重 |
| 连续增长 | 系统性漂移 | 触发短窗口后验更新 |

### 5.6 贝叶斯 LoRA 在线后验更新

对基础模型中的部分矩阵使用：

```text
W' = W + alpha / r * B A
```

优先插入：

- 时序注意力层；
- 动态模型头；
- `Q/R` 预测头；
- Track Query 更新层。

令低秩参数为 `phi = vec(A, B)`，用高斯近似维护后验：

```text
q_t(phi) = N(mu_t, Sigma_t)
```

事件触发后，使用短窗口数据 `D_t` 优化：

```text
q_t = argmin_q [ -E_q log p(D_t | phi)
                 + beta KL(q(phi) || q_{t-1}(phi)) ]
```

为应对异常量测使用 Student-t 似然，并限制后验变化：

```text
KL(q_t || q_{t-1}) <= epsilon
```

在线适应只更新低秩参数，基础模型主干冻结，从而降低显存、时延和灾难性遗忘风险。

## 六、训练方案

### 阶段一：自监督时序预训练

输入大量无标注雷达点迹或雷达图，进行掩码重建、下一帧预测、对比学习和时间顺序任务，学习通用表征。

### 阶段二：有监督检测、关联与跟踪训练

使用标注轨迹训练目标检测、数据关联、状态回归、存在概率、运动模式和协方差预测。

### 阶段三：接入可微贝叶斯滤波

将基础模型预测的 `F/Q/R` 和模式概率输入可微滤波器，以最终状态后验损失端到端训练。

### 阶段四：事件触发训练

在训练中模拟机动、噪声变化、漏检、虚警、传感器偏置和域切换，训练事件触发器或校准其统计阈值。

### 阶段五：贝叶斯 LoRA 在线适应

冻结基础模型，在域变化和非平稳序列上运行事件触发后验更新，评估适应速度、稳定性和校准性。

### 6.1 总损失

```text
L = lambda_1 L_state
  + lambda_2 L_NLL
  + lambda_3 L_assoc
  + lambda_4 L_mode
  + lambda_5 L_physics
  + lambda_6 L_calib
  + lambda_7 L_compute
```

其中：

- `L_state`：位置、速度、加速度误差；
- `L_NLL`：概率状态负对数似然；
- `L_assoc`：数据关联和身份一致性损失；
- `L_mode`：运动模式分类损失；
- `L_physics`：运动学连续性约束；
- `L_calib`：置信区间和协方差校准损失；
- `L_compute`：触发频率或在线更新成本约束。

## 七、实验设计

### 7.1 数据层次

#### 第一层：可控仿真数据

控制运动模式、噪声分布、漏检率、虚警率、目标数量和采样间隔，用于机制验证、消融和理论分析。

#### 第二层：公开雷达数据

选择包含点迹、雷达图或目标轨迹标注的数据，验证跨场景和跨目标类型性能。

#### 第三层：真实雷达数据

优先获取车载毫米波、路侧雷达、无人机或船舶雷达数据，用于验证真实杂波、量测偏差和长时间在线运行能力。

### 7.2 场景设置

- 匀速、匀加速、协调转弯和突发机动；
- 高、中、低 SNR；
- 高斯、重尾和时变噪声；
- 随机漏检、虚警和错误关联；
- 目标交叉、接近和短时遮挡；
- 训练/测试噪声、采样率、雷达平台和目标速度范围变化；
- 传感器偏置与逐渐漂移；
- 单目标、稀疏多目标和高密度多目标。

### 7.3 对比方法

**经典方法：** KF、EKF、UKF、IMM-EKF、IMM-UKF、JPDA、MHT、粒子滤波。

**深度方法：** LSTM/GRU、Temporal Transformer、Mamba/SSM、Deep Kalman Filter、Neural State Space、Track Query 模型。

**在线适应方法：** 无适应、周期性全参数微调、测试时自适应、普通 LoRA、固定周期 LoRA、事件触发普通 LoRA、贝叶斯 LoRA、完整方法。

## 八、评价指标

### 8.1 跟踪精度

- 位置 RMSE、MAE；
- 速度和加速度 RMSE；
- 航向误差；
- ADE、FDE；
- 最大误差和异常误差分位数。

### 8.2 多目标跟踪

- MOTA、MOTP、IDF1；
- ID Switch、轨迹碎片数；
- OSPA、GOSPA；
- 跟踪丢失率；
- 目标生成确认延迟；
- 错误终止率。

### 8.3 概率可靠性

- NLL；
- NIS、NEES；
- CRPS；
- ECE；
- 置信区间覆盖率；
- 协方差体积；
- 过度自信率。

重点检验：

```text

```

- 更新后的误差下降比例；

### 8.5 实时部署

## 十、理论与分析计划

### 10.1 事件触发统计分析

在模型匹配条件下，若创新满足高斯假设，则：

```text
NIS_t ~ chi-square(d)
```

据此设计基础阈值，并分析给定显著性水平下的误报概率。进一步分析 CUSUM 在模型变化前后的检测延迟、平均触发间隔和漏检概率。

### 10.2 在线后验稳定性分析

在：

```text
KL(q_t || q_{t-1}) <= epsilon
```

以及 `Q_t`、`R_t` 正定的条件下，研究低秩参数有界性、滤波协方差正定性和状态估计误差的有界性。理论分析至少应形成稳定性条件、命题或可复现实验验证。

### 10.3 低秩后验到状态后验的传播

通过参数采样、线性化或 Delta method，将适配参数后验引入状态协方差：

```text
P_total = P_filter + P_model
```

分析贝叶斯 LoRA 的模型不确定性是否能够改善异常场景下的置信区间可靠性。

## 十四、可行性与风险控制

### 可行性

- 第一阶段仅依赖点迹级数据，降低原始 IQ 数据和标注门槛；
- 可先使用仿真和公开数据建立完整基线；
- 可微 EKF/UKF 和 LoRA 均有成熟实现基础；
- 各研究内容能够逐步形成独立论文，不依赖一次性完成全部系统。

### 主要风险与对策

1. **模块堆叠、创新不足：**将主问题聚焦为“非平稳环境下可靠、低成本在线贝叶斯跟踪”，所有模块围绕该问题服务。
2. **贝叶斯 LoRA 后验不严谨：**先采用低秩增量矩阵或 Laplace 近似，明确说明近似假设，并研究参数不唯一性。
3. **异常量测污染在线更新：**使用关联门控、Student-t 似然、短窗口 replay、KL 约束和更新冷却时间。
4. **只有仿真没有真实数据：**尽早搭建公开数据基线，争取加入真实毫米波或路侧雷达点迹数据。
5. **基础模型规模不足：**在数据规模有限时使用“雷达时序预训练模型”表述，不夸大为通用基础模型；通过跨场景、跨雷达迁移证明其价值。
6. **实时性不足：**从点迹级输入、冻结主干和低秩更新开始，记录端到端延迟与触发率。

## 十五、最终研究定位

> **用雷达时序基础模型学习复杂运动，用可微贝叶斯滤波保证概率状态估计，用位置-速度联合创新判断何时适应，用事件触发贝叶斯 LoRA 实现低成本在线更新。**

博士论文主线应始终围绕：

```text
非平稳雷达环境下的可靠在线贝叶斯跟踪
```

而不是泛化为把所有大模型组件叠加到雷达系统中。该框架具有明确的应用背景、递进的科学问题、算法和理论研究空间，以及仿真、公开数据和真实雷达数据的验证路径。
